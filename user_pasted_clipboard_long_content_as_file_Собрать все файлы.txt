Разобрать слова на токены

Используйте регулярные выражения, чтобы разбивать каждое слово на отдельные символы‑токены.
Запишите для каждого слова список индексов первых появлений токенов – как в Citation 3.
Построить таблицу «токен → буква»

Сначала фиксируйте токены, которые встречаются только в коротких словах (2‑3 символа). Это сильно ограничит количество возможных комбинаций.
Затем постепенно расширяйте поиск:
Омофоны – если два токена звучат одинаково, они могут быть заменены друг другом.
Диграфы – допускается, что один токен обозначает две буквы (например, «TH» → «ТХ»).
Проверка совместности

После каждой попытки сопоставления проверяйте, не конфликтует ли она с уже найденными парами.
Если встречается противоречие, откатитесь к предыдущему шагу и попробуйте другую комбинацию.
Итеративный поиск решений

Используйте алгоритм backtracking:
Copy
python
def solve(mapping, remaining_tokens):
    if not remaining_tokens:
        return mapping  # решение найдено
    token = remaining_tokens.pop()
    for possible_letter in alphabet:
        if is_consistent(token, possible_letter, mapping):
            new_mapping = mapping.copy()
            new_mapping[token] = possible_letter
            result = solve(new_mapping, remaining_tokens.copy())
            if result: return result
    return None
Если решение не найдено, попробуйте расширить словарь (wordfreq) и добавить возможные диграфы.
Оценка результатов

После получения карты токен‑буква сравните декодированные слова с ожидаемыми английскими словами (или их частотным профилем).
Если часть слов остаётся непонятной, возможно, они действительно используют нестандартные шифры – в таком случае можно добавить новые правила (например, «O» появляется редко).
